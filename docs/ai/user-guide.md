# user-guide.md — 用户使用手册

> 无需阅读代码即可了解、操作产品。本文按「在线 / 离线」两种场景，从角色讲起，按操作流程组织。

## 进入系统

- **在线**：浏览器打开 https://tag-pricing-calculator-v5.pages.dev ，需登录（管理员 / 业务员 / 访客）。
- **离线**：本地双击 `index.html`（或起 `python3 -m http.server 8080`），无需登录.

## 角色与权限

| 角色 | 能做什么 |
|---|---|
| **管理员** | 全部功能 + 管理账号 + 内联编辑报价表 + 上传共享默认数据 |
| **业务员** | 报价、查看数据管理；默认数据为只读，不可在线修改 / 上传 |
| **访客** | 仅见智能报价计算器 |

## 主界面（左侧导航）

- **智能报价计算器**：日常报价。
- **报价表组查询**：浏览各报价表价格。
- **个人主页**：报价设置、数据管理、快照与统计。

## 智能报价计算器

1. **选纸张**：SKU 芯片直选（默认），或在个人主页切到「下拉双列模糊搜索」。
2. **填尺寸**：吊牌展开尺寸（长 × 宽）；是否出血决定是否四周自动加 3mm。
3. **选工艺 / 附加工艺**：按报价时间段匹配；默认折叠面板可展开。
4. **选吊绳**：切换吊绳类型即刻重算报价。
5. **选数量档位 / 客户等级**：决定走哪个规格档位与毛利系数。
6. **三档计价**自动选择：标准报价（查规格） / 直接系数 / 批量直接报价。
7. 结果：多纸张合计 + 单品明细成本与报价；支持「保存报价」进历史。

> 附加工艺、吊绳面板默认折叠；纸张有「特殊备注」时会直接影响匹配（可在报价表组查询里查看）。

## 报价表组查询

- 左侧选择「报价表组 → 报价表 → 纸张」。
- 纸种在表格下方独立框体显示备注（如唛头：织边带 / 电脑机）。
- 顶部分类搜索纸张（简称 / 全称 / 多关键词）。
- 超级管理员：表头、规格行、代码 / 面积单元格可内联编辑（编辑后 `上传为默认数据` 可同步云端）。

## 个人主页

### 报价设置

默认客户等级 / 默认吊绳 / 默认纸张 / 是否隐藏纸张序号 / 纸张选择模式 / 小数位 / 个性化字号 / 桌面 iPad 扁平布局开关等。

### 数据管理（4 个标签页）

- **价格配置**：本地备份、JSON / Excel 导入导出、重置为出厂默认。
  - 注意：「直接系数」只读报价表 Sheet 的三行数据，改它请在 Excel 改后重新导入。
- **报价历史**：查看 / 删除 / 重新载入历史报价。
- **在线修改**（管理员）：在线新增 / 重命名 / 删除报价表组与报价表、调整归属；选目标报价表 → 导出「含现有数据的模板」→ 修改后导入 → 原地覆盖该表。
- **云同步**：目前为占位界面，暂未实现。

### 快照与统计报表

- 自动统计：月度报价次数、热销尺寸、利润分布（柱状图 + 汇总卡片）。
- 支持导出统计报表（Excel，三个工作表）。
- 本地快照记录报价表组结构，可导出快照集合 JSON。

## 数据与升级说明

- 数据默认存本地浏览器（`localStorage`）；换设备 / 清缓存前请先备份。
- 管理员在「价格配置 → 上传为默认数据」后，其它账号登录会自动应用共享默认数据。
- 系统自带版本迁移，老版本数据自动升级，无需手动处理。
- 改价格：由管理员在官方 Excel 报价表中调整后导入，或在线上内联编辑并上传为默认数据。

## 常见问题

- **报价没变化？** 确认选中了纸张、填了尺寸、数量档位与客户等级；切换吊绳已即时重算。
- **数据被清了？** 重置「恢复出厂」或清浏览器缓存会清空本地配置；报价历史与本地快照不受重置影响。重要数据先备份。
- **线上不能改价格？** 默认数据为只读，仅超级管理员可改并上传。
