# DESIGN.md — 项目视觉规范定义

> 前端视觉与交互约定。改样式 / 加页面前先读本文件，保持品牌一致性。

## 品牌基调

- 品牌：**KOKALabel**，主色为 KOKA 蓝，视觉语言偏「扁平、留白、卡片化」。
- 图标：`assets/` 下 KOKA 菱形铅笔标（favicon / apple-touch-icon）。**不使用**任何「亲成」风格素材。

## 设计 Token（`css/style.css` → `:root`，改色优先改这些变量）

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#0f6fc4` | 主色 / 品牌蓝（按钮、激活、链接） |
| `--brand-dark` | `#0a4f8a` | 主色深（标题、hover、强调） |
| `--brand-light` | `#e8f2fb` | 主色浅（选中背景 / 高亮块） |
| `--text` | `#1f2937` | 正文主文字 |
| `--text-secondary` | `#6b7280` | 次要文字 / 说明 |
| `--bg` | `#f3f6fa` | 页面背景 |
| `--card` | `#ffffff` | 卡片 / 面板背景 |
| `--danger` | `#dc2626` | 错误 / 危险 |
| `--danger-light` / `--danger-border` | `#fff5f5` / `#fecaca` | 错误提示背景 / 描边 |
| `--success` | `#059669` | 成功 / 上传默认数据按钮 |
| `--border` | `#dbe4f0` | 分隔线 / 卡片描边 |
| `--shadow` | `0 4px 14px rgba(15,111,196,.12)` | 卡片投影（蓝色柔光） |
| `--radius` | `12px` | 卡片圆角 |

> 附加工艺 / 风险提示常用琥珀色调：背景 `#fffbeb`、左边框 `#f59e0b`、文字 `#92400e`（见 `.notes` 备注框）。

## 布局

- **桌面 / iPad**：左侧固定 `sidenav`（品牌名 + 三个导航按钮）+ 右侧主区 `app-shell`（扁平化宽泛式）。
- **移动端**：自动切换为「垂直纵深式」布局，导航纵向堆叠。
- 三个页面：智能报价计算器 / 报价表组查询 / 个人主页。
- 内容多用白底卡片（`--card` + `--shadow` + `--radius`），保持留白。

## 排版与间距

- 正文：系统字体栈，主打黑。
- 标题用 `--brand-dark` 突出；次要说明用 `--text-secondary` 小字号。
- 页面标题：`card-title`（h2）；区块说明：`setting-desc`。
- 卡片内间距宽松；列表行高不小于当前字体 1.5 倍，保证可读性。

## 关键组件规范

- **导航**：`nav-btn`，当前页用 `active`（主色高亮）。
- **标签页**：`.tab` + `.active`；数据管理有 价格配置 / 报价历史 / 在线修改 / 云同步 四个 tab。
- **按钮**：`.btn`，主按钮品牌蓝、`.sm` 小型、`.btn.danger-outline` 危险描边、`.btn.sm` 绿色实心用于「上传为默认数据」。
- **表单**：标签 + 输入控件，必填项沿用既有约束；错误用 `.danger` 提示。
- **表格**：`data-table`，报价 / 工艺 / 直接系数 / 批量直接 / 吊绳 / 邮费 多表；可编辑单元格 `.price-editable`（管理员内联编辑）。
- **备注框**：`.notes`（琥珀框），报价表有备注时展示「报价表备注：…」。
- **折叠面板**：`.fold` + `.open` / `.collapsed`（吊绳、附加工艺默认折叠），标题可点击 / 回车切换，带 `aria-expanded`。

## 交互与无障碍约定

- 交互反馈尽量即时（切换即重算报价）。
- 可点击元素提供 hover / focus 态；键盘可达（回车可折叠）。
- 颜色对比度符合一般可读性（正文 `--text` / 主色均足以与白底区分）。
- 保留 `--danger` / `--success` 的语义色，不引入额外高饱和色块，避免视觉噪声。

## 改样式规范

- 新颜色优先落到 `:root` token，而非硬编码，保证全站一致。
- 页面结构改动同步 `index.html` 对应容器 + `app.js` 渲染 / 事件绑定。
- 重要视觉改动后，在桌面与移动两档各看一眼截图，确认布局无溢出。
