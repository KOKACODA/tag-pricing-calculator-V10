# project-overview.md — 项目整体概述

> 本文是了解「这是什么、能干什么、怎么跑起来」的第一份文档。技术细节见 `architecture.md`，操作见 `user-guide.md`。

## 一句话

KOKALabel 报价系统：面向**吊牌 / 标签 / 不干胶印刷业务**的在线报价计算工具，纯前端原生实现，支持多报价表、Excel 导入导出与账号登录。

## 核心价值

- 输入吊牌 / 标签的尺寸、纸张、材质、工艺、数量、吊绳、邮费、客户等级 → 输出成本与报价。
- 数据以 Excel 报价表（每张纸一个 Sheet）为唯一事实源，可视化浏览、内联编辑、导入导出。
- 管理员可一键把当前配置上传为**全用户共享默认数据**，云端同步各角色。

## 技术栈

- 原生 HTML + CSS + JavaScript（无框架、无构建）。
- SheetJS（`js/vendor/xlsx.full.min.js`，本地化，离线可用）负责 Excel 解析 / 导出。
- `localStorage` 存储用户数据；`dataVersion` 版本号 + 迁移链保证老用户平滑升级。
- 线上：Cloudflare Pages + Pages Functions + KV 提供账号登录与默认数据分享。
  - 本地 `file://` 离线打开：**不使用登录体系**，全功能可用。

## 线上地址与版本

- 线上：https://tag-pricing-calculator-v5.pages.dev
- 当前版本：**v10.9.0**（分支持续更新，见 `CHANGELOG.md`）。

## 功能一览

1. **账号登录**：管理员 / 业务员 / 访客 三级角色。
   - 管理员：可管理账号（增删改 / 启停 / 改密 / 设时长）、上传共享默认数据、内联编辑报价表。
   - 业务员：可报价、查看数据管理；默认数据为只读。
   - 访客：仅见智能报价计算器。
2. **智能报价计算器**：多纸张、每张独立尺寸 / 材质 / 工艺；三种计价方式：
   - **标准报价**（查规格档位）、**直接系数**（按系数/面积）、**批量直接报价**。
   - 吊绳、邮费（两档对话框）、附加工艺截系数加成；吊牌成本合计。
   - 是否出血规则：默认出血四周加 3mm；不出血走区间匹配规格。
3. **报价表组查询**：按「报价表组 → 报价表 → 纸张」浏览价格表；纸种有备注时在表格下方独立框体展示；支持纸张模糊搜索；超级管理员可内联编辑表头 / 行列。
4. **个人主页**：
   - 报价设置（默认等级 / 吊绳 / 纸张 / 字号 / 纸张选择模式 / 小数位）。
   - 数据管理（4 个标签页）：
     - **价格配置**：备份恢复、JSON/Excel 导入导出、重置为默认。
     - **报价历史**：保存快照 + 输入参数，查看 / 删除 / 重新载入。
     - **在线修改**（管理员）：报价表组 / 报价表在线增删改名与调整归属；按模板修改后原地覆盖目标报价表数据。
     - **云同步**：占位 UI（待实现）。
   - **快照与统计报表**：月度报价次数 / 热销尺寸 / 利润分布柱状图，支持导出统计报表；本地快照记录报价表组结构。
5. **离线可用**：SheetJS 已本地化，导出 / 导入 Excel 无需联网。

## 启动方式

```bash
git clone https://github.com/KOKACODA/tag-pricing-calculator-V10.git
cd tag-pricing-calculator-v5 && git checkout v8
# 直接双击 index.html，或用本地静态服务器：
python3 -m http.server 8080
```

## 部署

- Cloudflare Pages（分支 `v8`），Git 自动部署已断，发版用 wrangler 直传（详见 `docs/部署日志.md`）。
- 后端：`functions/`（Pages Functions），KV 命名空间 `AUTH` 绑定于 `wrangler.toml`。
