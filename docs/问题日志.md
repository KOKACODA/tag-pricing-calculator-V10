## v13.0 回搬期发现并修复

### ✅ 企业版历史归档被公网服务（2026-09-28，已修复）

- **现象**：`archive/`（同事版 V9/V10 系列历史归档，含企业定制品牌）随 `wrangler pages deploy .` 被上传，公网可直接读取（`https://tag-pricing-calculator-v5.pages.dev/archive/.../V10.5/js/app.js` 返回 200，`application/javascript`），与「归档仅记录、不部署」原则相悖。
- **排查**：`.assetsignore` 对 Pages 直传无效（该机制仅适用于 Workers Static Assets；实测上传文件数未减少，archive 仍在部署快照内）。
- **修复**：新增 `functions/archive/_middleware.js`，拦截 `/archive/*` 返回 404（Pages Functions 优先于静态资源）；重新部署 `4966bc4f`；验证 archive 各路径（V10.5 index/data、V9.8 data）均 404，站点本体不受影响。
- **备注**：文件仍存在部署快照内存（Pages 无忽略机制），但公网不可读；若需彻底不上传，需改变部署输出目录（另议）。

### ✅ 顶层文档企业定制品牌词残留（2026-09-28，已修复）

- **现象**：`CHANGELOG.md`、`docs/CHANGELOG.md`、`docs/部署日志.md`、`docs/回搬记录-v13.0.md`、`docs/ai/TODO.md` 共 16 处残留企业定制品牌词。
- **修复**：匿名化为「企业定制品牌」，顶层 0 残留；`archive/` 历史归档保留原貌。

## 已确认问题

### 1. ✅ 标准报价在纸张或工艺缺价时仍可能生成正式报价

- 状态：**已修复（v8.2）**。`costKnown` 改为 `!hasMissingTier`，纸张/工艺/吊绳/邮费任一缺价都正确标记「部分缺价」，不再用 0 凑成本生成报价。

### 2. ✅ 多纸张报价的邮费受纸张排列顺序影响

- 状态：**已消除（v8.0）**。邮费重构后移除小面积折扣逻辑，新邮费不再依赖纸张面积与排列顺序。

### 3. ✅ 面积规格在 6000mm² 边界发生代码和价格回落

- 状态：**已修复（v8.2）**。强制映射范围由 5500–5999 扩展为 5500–6000，6000 强制命中 `006`。

### 4. ✅ 数据恢复和邮费导入持久化不完整

- 状态：**已修复（v8.2）**。
  - 快照恢复补上吊绳/邮费配置还原。
  - 邮费 Excel 导入后写入 localStorage。
  - 吊绳选项重建后事件重绑定（v7.9 已修复 `bindRopeEvents()`）。

### 5. ⚠️ Excel 模板逻辑与多报价表结构冲突

- 状态：**部分保留（业务上正常）**。跨报价表重复纸张简称属于正常业务——不同小组会使用相同简称、不同计价，Sheet 重名不作为 bug 处理。
- 遗留（暂不处理）：模板仍遍历全部纸张而非当前报价表；元信息统一写成当前报价表。

### 6. ✅ 默认纸张设置没有真正应用到计算器

- 状态：**已修复（v8.2）**。计算器初始化纸张时优先使用个人主页设置的默认纸张（若存在于当前报价表）。

### 7. ⚠️ 直接系数的中间等级存在浮点舍入偏差

- 状态：**已知，未处理**。如 1.275 会显示为 1.27（浮点误差）。不影响主流程，待后续处理。

### 8. ⚠️ Excel/JSON 导入校验与输出转义不足

- 状态：**已知，未处理**。负价格、规格乱序、直接系数异常未完整拦截；部分导入状态通过未转义 innerHTML 输出。待后续处理。
