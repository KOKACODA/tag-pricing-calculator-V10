# 功能差别标记：v9.8.0（仓库基线） vs v10.6.0（当前线上）

> 本文档是「9.8 功能保留清单」的唯一标记入口。
> v10.6 由同事 v10.5 整合而来，部分 9.8 功能在整合中被替代或移除。
> **后续版本需要把下列「9.8 独有」功能加回时，以本文档为准逐条核对。**
> 维护规则：加回一项 → 在对应行标注「已加回 vX.Y + 日期」。

- 基线说明：v9.8.0 = 仓库 `v8` 分支 commit `c3bc57b`（含「在线修改」功能）；v10.6.0 = 当前工作树。
- 账号登录体系：两版均为 9.8 体系（管理员/业务员/访客，Pages Functions + KV）。v10.6 明确不使用 v10.5 同事版的登录改动。

## 三、两版共有（无差别）

- 报价计算核心（纸张面积系数、标准/直接/批量直接报价、吊绳/邮费/工艺加成、客户等级毛利）。
- 报价历史、本地快照、Excel 导入导出（报价表/吊绳/邮费）、JSON 配置导入导出、本地备份。
- 账号登录体系（9.8 版：管理员/业务员/访客 + KV 会话 + 默认数据自动应用）。
- 品牌与图标：KOKA（v10.6 明确保留，不采用 v10.5 的「亲成」品牌与图标）。
- 云同步 tab：两版均为占位 UI。

## 四、v10.6 明确不做（用户拍板）

- 品牌：保持 KOKALabel，不换「亲成」（v10.5 的图标与公司名改动全部回退）。
- 登录：保持 9.8 体系，不采用 v10.5 的登录实现。
