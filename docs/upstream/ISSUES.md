## v10.8.0 新增记录（2026-09-24）

### A. ✅ 吊绳「不加吊绳」被误报「未设置 1000 张基准价」（P0）

- 现象：「不加吊绳」全档位定价本来就是 0，但计算时弹出「吊绳「不加吊绳」未设置 1000 张基准价」，
  且整单被标记为缺价（结果是 0）。
- 根因：`getRopeBasePrice()` 对 `≤0` 的一律返回 `null`，把合法的 0 价当成"没设价"。
- 状态：**已修复（v10.8.0）**。新增 `isFreeRope()` 识别全 0 价的免费选项，基准价补 0；
  同时吊绳 Excel 导入改为把空单元格保留为 `null`（不再折算成 0），缺价警示得以保留。

### B. ✅ 切换吊绳后报价不刷新

- 根因 1：`rebuildRopeUI()` 重渲染时按 `APP_PROFILE.defaultRope` 重置选中项，把用户选的吊绳换回默认，
  而调用顺序是「先 rebuild 再 onCalculate」→ 报价按被换掉的吊绳计算。
- 根因 2：「恢复默认配置」里 `initOptions()` 重写 `els.rope.innerHTML` 后没有重新绑定 change 事件。
- 状态：**已修复（v10.8.0）**。`rebuildRopeUI()` 保留当前选中项 + 重绑事件 + 刷新摘要；
  `initOptions()` 改走 `rebuildRopeUI()`。

### C. ✅ 报价表模板元信息写错报价表

- 现象：模板/导出时「所属小组」「总报价表」一律取"当前报价表"，多报价表（现 4 张）时会标错。
- 状态：**已修复（v10.8.0）**（对应下方遗留项 5 的后半段）。改为按纸张所属报价表取名。

### D. ✅ 其他清理

- `resetToDefaults` 中 `renderRopeRadios();` 是空调用（返回值被丢弃，未写入 DOM）→ 已移除。
- `parsePaperExcel` 开头两行紧邻 `throw`，第二行永不可达（死代码）→ 已删除。

## 已确认问题

### 1. ✅ 标准报价在纸张或工艺缺价时仍可能生成正式报价

- 状态：**已修复（v8.2）**。`costKnown` 改为 `!hasMissingTier`，纸张/工艺/吊绳/邮费任一缺价都正确标记「部分缺价」，不再用 0 凑成本生成报价。

### 2. ✅ 多纸张报价的邮费受纸张排列顺序影响

- 状态：**已消除（v8.0）**。邮费重构后移除小面积折扣逻辑，新邮费不再依赖纸张面积与排列顺序。

### 3. ✅ 面积规格在 6000mm² 边界发生代码和价格回落

- 状态：**已修复（v8.2）**。强制映射范围由 5500–5999 扩展为 5500–6000，6000 强制命中 `006`。

### 4. ✅ 数据恢复和邮费导入持久化不完整

- 状态：**已修复（v8.2）**。
  - 快照恢复补上吊绳/邮费配置还原。
  - 邮费 Excel 导入后写入 localStorage。
  - 吊绳选项重建后事件重绑定（v7.9 已修复 `bindRopeEvents()`）。

### 5. ⚠️ Excel 模板逻辑与多报价表结构冲突

- 状态：**部分保留（业务上正常）**。跨报价表重复纸张简称属于正常业务——不同小组会使用相同简称、不同计价，Sheet 重名不作为 bug 处理。
- ✅ 元信息统一写成当前报价表 → **已修复（v10.8.0）**，改为按纸张所属报价表取名（见上文 C）。
- 模板仍遍历全部纸张而非当前报价表 → **保留**：模板设计上就是全量模板，便于一次维护全部报价表。

### 6. ✅ 默认纸张设置没有真正应用到计算器

- 状态：**已修复（v8.2）**。计算器初始化纸张时优先使用个人主页设置的默认纸张（若存在于当前报价表）。

### 7. ⚠️ 直接系数的中间等级存在浮点舍入偏差

- 状态：**已知，未处理**。如 1.275 会显示为 1.27（浮点误差）。不影响主流程，待后续处理。

### 8. ⚠️ Excel/JSON 导入校验与输出转义不足
