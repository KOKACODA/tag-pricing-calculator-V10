## 一、整体风格

**扁平 + 卡片式 + 蓝色品牌色**。没有渐变、没有重阴影、没有装饰性动效。
密度偏高（信息量大），但在移动端会切换成纵向堆叠布局。

从 v9.7 起为「扁平化宽泛式」：卡片浅底 + 细边框 + 圆角，弱化阴影。

## 三、排版与响应式

### 3.1 尺寸一律用 `clamp()`

项目所有字号 / 间距 / 圆角都用 `clamp(min, 视口比例, max)`，实现"无断点自适应"：

```css
font-size: clamp(0.75rem, 3.5vw, 0.875rem);
padding:   clamp(0.625rem, 3vw, 0.75rem) clamp(0.75rem, 4vw, 1rem);
```

这样手机与桌面共用一套规则，只在必要时（<480px）加断点做布局换行。

### 3.2 两套布局模式

| 模式 | 类名 | 用在哪 |
|---|---|---|
| 纵向堆叠 | `ui-vertical` | 手机 |
| 扁平排布 | `ui-flat` | 电脑 / 平板 |

### 3.3 界面字号（个性化）

用户可调界面字号，**以 px 为核心**：

| 常量 | 值 |
|---|---|
| `FONT_BASE_PX` | 16（= 100%） |
| `FONT_MIN_PX` | 8 |
| `FONT_MAX_PX` | 32 |

- 实现：`document.documentElement.style.zoom = px / 16`
- 持久化：`localStorage.uiFontScale`
- 面板显示「当前字号：16px（100%）」，支持手输 px，越界弹 toast 拒绝
- 仅影响**本机**显示，不影响数据与他人

## 四、组件模式（本项目没有组件库，以下是复用的样式模式）

| 模式 | 类名 / id | 说明 |
|---|---|---|
| 卡片 | `.card` + `.card-title` | 所有区块的基本容器 |

## 五、交互约定

1. **破坏性操作必须二次确认** —— 改价、清空价格、删除报价表都用 `confirm()` 并显示原值/新值。
2. **就地编辑**：点单元格 → 变输入框 → `Enter` 提交 / `Esc` 取消 / `blur` 提交。
3. **权限拦截**：所有编辑入口统一走 `KOKA.canEditQuote()`，非管理员点击提示"只读"。
4. **实时计算**：改任何参数立即重算（无"计算"按钮）。
5. **空状态要隐藏而非留白**：如报价表无备注 → 备注框整块 `hidden`。

## 六、注意

  新增样式请**追加在文件末尾并注明版本号**，不要中途插入历史段落。
- 品牌显示文案「**KOKA**」；CSS 里的 `koka*` 类名是历史内部标识符，**保持原名勿改**。
