# v12.7 计划文档：指定报价表改占位 + 术语澄清 + 分页修复 + 按钮统一 + 在线模板

> 编制：2026-10-10 ｜ 状态：**已实施并发布（v12.7）**

## 一、需求与实施

### 1. 「指定报价表」改为**仅占位、不生效**（用户澄清）
- **保留**：字段 `targetPriceListId`（吊绳/邮费条目）、Excel 模板「指定报价表」列、导入解析、
  报价表组查询的「指定报价表」展示列（`全局` / `→ 3楼`）、「关闭指定」按钮。
- **撤销生效逻辑**：`getAvailableRopes/getAvailableRegions` 不再过滤/排序（恒返回全量）；
  移除切表时的可用性自动切换与提示。
- 即：**字段可填、界面可见、暂不影响任何计算与显示**——后续需要启用时，恢复 v12.5 的两行过滤逻辑即可。

### 2. 术语澄清（写入文档与记忆）
- **默认语境下「报价表」= 纸张报价表**；吊绳/邮费须特别表述为「吊绳报价」「邮费报价」。

### 3. 修复：吊绳/邮费视图误显示纸张分页条（"第 2/33 张"）
- **根因**：`renderPagination` 给 `#paginationBar` 设了 **inline `display:flex`**，
  优先级高于 `hidden` 属性的 UA 样式 → 切到吊绳/邮费视图时未被隐藏。
- **修复**：`#page-table [data-tview][hidden] { display: none !important; }`（一行 CSS，覆盖 inline）。
- 邮费视图同源，一并修复。

### 4. 云端上传按钮统一改名
- 「上传为默认数据」+「保存为全局默认（云端共享）」→ 统一为 **「保存到云端」**；
- 相关 confirm/toast 文案全部统一；
- 语义强化：**所有管理员在线修改仅写本地，必须点「保存到云端」才同步云端**。

### 5. 新增：在线模板——「在线制作纸张报价表」（初版）
在线修改 tab 新增区块三，实现**全字段在线制作/编辑纸张报价表**：
- 纸张选择下拉 + **新建纸张**（自动归属当前纸张报价表 + 初始 1 行规格）；
- **属性表单**（全称 / 简称 / 折扣系数 / 所属纸张报价表 / 直接系数三行 / 批量直接面积与档位价格 / 出血提示）；
- **规格价格矩阵**（代码、最大含出血面积、各档价格——单元格点击即改，复用全局就地编辑链路）；
- **工艺价格矩阵**（＋ 工艺行 / 行内 ✕ 删除 / 各档价格就地编辑）；
- **＋ 规格行**（复用现有 `addSpecRow`）；
- **保存到本地**（写 localStorage，提示"如需全员共享请点保存到云端"）。
- 实现要点：渲染前同步 `currentPaperIndex` 到目标纸张 → 复用既有 `startCellEdit/applyPriceEdit` 链路，
  **零计算逻辑改动**；直接系数分三步输入（档位/最高/最低），中间态保留输入、有效性由 `paperHasDirectCoeff` 判定。
