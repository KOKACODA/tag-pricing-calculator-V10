## 二、设计（语义定义与决策）

### 2.1 字段
- `rope.targetPriceListId` / `region.targetPriceListId`：字符串，`""` = 全局生效（默认，兼容旧数据）。
- 仅在模板/表格中以**报价表名称**呈现（如「3楼」），内部存 id（`priceList2`）。

### 2.2 计算与显示逻辑（**核心**）
| 场景 | 规则 |
|---|---|
| 吊绳/邮费**选项列表**（计算器） | 条目为空 → 全部报价表可选；指定了 → **仅目标报价表可见**（其他表隐藏该条目） |
| **优先** | 指定项在其目标报价表的列表中**排最前**（排序优先；不自动改选中值，避免篡改用户默认） |
| **兜底 1** | 当前报价表过滤后若无任何可用条目 → 回退显示全部全局条目（绝不出现空列表） |
| **兜底 2** | 切换纸张报价表后，若当前选中的吊绳/地区已不可用 → 自动切到第一个可用项并提示 |
| 价格表视图（报价表组查询） | 显示**全部**条目 + 「指定」列（`全局` / `→3楼`）；指定项高亮 |
| 「关闭指定」按钮 | 吊绳价格视图、邮费价格视图**各一个**按钮：一键清空全部条目的指定（全部恢复全局） |
| 计算本身 | 不变——选项已过滤，`calculate` 按 id 查价逻辑不动（零计算逻辑风险） |
| 导入/导出/备份 | 字段随配置整体往返（JSON 备份天然带；Excel 模板加列） |

### 2.3 模板列（Excel）
- **吊绳模板**：表头末列加「指定报价表」（如 `吊绳名称 | 500 | … | 50000 | 指定报价表`），示例行留空。
- **邮费模板**：表头末列加「指定报价表」（在「大于10000」系数列之后）。
- **解析兼容**：按表头名定位该列；**旧模板（无此列）照常导入**（视为全部全局）；
  填写的名称匹配不到报价表 → 忽略并警告（不阻断导入）。
- **注意**：吊绳"不加吊绳"行与邮费示例行保持全局（留空）。
