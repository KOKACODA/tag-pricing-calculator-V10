## 2026-09-15

### v10.7.1 品牌回归 + 个性化卡死修复 + 字号 px 手输 + 账号体系同步 v10.5

- **tag** `v10.7.1` ｜ **分支** `v10.7-dev` ｜ **commit** `c03e495`（功能）+ `69c1098`（.gitignore 硬化）
- **线上**：title = `KOKALabel报价系统 v10.7.1`

> 基线是**外部交付的 KOKALabel v10.7.0 完整代码包**（62 文件）。

**四项需求与实现**

1. **品牌与图标换回「KOKA」**
   - title / 文案 / 导出文件名前缀全改「KOKA」
   - 图标统一收进 `assets/`（favicon.svg/ico/png + apple-touch-icon + logo），
     `index.html` / `login.html` 引用改 `assets/*`，缓存参数同步更新

2. **账号登录体系同步 v10.5**（★ 原计划是"保留 v10.7 自己的三级体系"，执行前被用户推翻）
   - `js/auth.js` 整文件替换为 v10.5 版（305 行）：
     `superadmin/admin/sales/visitor` + `roleRank()` + `/api/quote`
   - `functions/` 全量对齐 v10.5，新增 `api/auth/status.js`
   - `app.js` 两处权限判定由 `role === "admin"` 改为 `KOKA.roleNum() >= 2`
   - **发现**：v10.5.0 的 `auth.js` 与 `functions/` 与目标版本**几乎完全一致**
     （`git diff` 显示 auth.js 真实差异仅 2 行头注释，functions 7 个文件 SHA 全等）
     → 实际只需新增 `status.js` 一个文件

3. **修复个性化面板「卡死」**（P0）
   - **根因**：HTML 元素 id 是 `personalizePanel`（v10.2 改内联面板时更名），
     而 JS 里 `els.personalizeModal = getElementById("personalizeModal")` 读的是旧名
     → 恒为 `null` → 点击时 `if (els.personalizeModal)` 判空直接跳过 `classList.toggle("open")`
     → 面板永远打不开（用户体感 = 卡死）
   - **修复**：6 处 `personalizeModal` → `personalizePanel`

4. **字号显示与手动输入（px 为核心）**
   - 新增 `FONT_BASE_PX(16)` / `FONT_MIN_PX(8)` / `FONT_MAX_PX(32)` 与 `pxToScale()`
   - 面板实时显示「当前字号：16px（100%）」
   - 输入框由百分比 50~200 改为 **px 8~32**，越界 toast 拒绝
   - 缩放实现：`document.documentElement.style.zoom` + `localStorage.uiFontScale`

**坑**
- 版本号 `"version": "10.7.0"` 存在无空格变体 `version: "10.7.0",`，纯字符串替换会漏 →
  改用 python 正则 `re.subn(r'(version\s*:\s*["\'])X\.Y\.Z(["\'])', ...)`
- `login.html` 里残留 `?v=10.6.0` 三处，需一并改

**验证**：jsdom 同进程静态服务器实测，9 项全绿（面板可开、字号 px 生效、越界拒绝、恢复默认）；
迁移链 `[v7.8]→[v8.4]→[v9.0.1]→[v9.5.1]→[v9.9.0]` 全部正常执行。

## 2026-09-24

### v10.8.0 是否出血规则 + 唛头报价表 + 吊绳缺陷修复

- **tag** `v10.8.0` ｜ **分支** `v10.8-dev` ｜ **commit** `90b0c00`
- **线上**：title = `KOKALabel报价系统 v10.8.0`

**需求（一次 7 条）**
1. 吊绳「不加吊绳」没设 1000 张基准价 → 定价 0 却报错，修
2. 新增规则「是否出血」（默认出血）：出血=否时，「最大含出血面积」列仍按该字段查，
   但计算改为**区间匹配**（例：0-1040-1280-1600-2000-2400-2800-3200-3600-4000）
3. 把用户给的唛头报价表增加为默认报价表
4. 报价表组查询：报价表有备注时，在**顶部另起一行的框体**里显示
5. 切换吊绳报价规格可能不刷新报价 → 修
6. 检查其他 bug
7. 版本管理 + 日志 + 推送部署

**执行前用户拍板的 4 个决策**
- 版本号 → **v10.8.0**
- 「是否出血」层级 → **按报价表**（非按纸张）
- 出血=否的取档 → **向上取：取最小的 ≥ 实际面积那档**
- 唛头表归属 → **新建「唛头」报价表组**

**实现**

*① 是否出血规则*
- 报价表新增 `bleed` 字段（默认 `true`）
- `bleed=false` 时面积**不加 3mm**；仍读「最大含出血面积」列，向上取档
- 不出血表跳过 `forceSpecByArea()` 的 005/055/006 强制映射（吊牌专用硬编码）
- 结果表 `▲▼` 代码切换（`onCodeSwitch`）同步按同一口径取档
- Excel 模板 / 导出新增「是否出血」行；导入按 `否/no/false/0/n` 判定，留空保持原值；
  信息区扫描窗口由 8 行放宽到 16 行
- 新增 `currentPriceListBleeds()` / `priceListBleeds()` / `getPriceListNote()`

*② 唛头报价表*
- 新增「唛头小组」（`group3`），下挂 `priceList3 织边带（消光带）`、`priceList4 电脑机`
- 各 9 档规格（代码 `1.3*8`…`5*8`，面积 1040…4000），
  档位 1000/2000/3000/5000/10000 有价，500/20000/50000 无价
- 均 `bleed:false`、折扣系数 1、带备注
- 迁移 `migrateV1080BleedAndMaitou`（`dataVersion` → `10.8.0`）：
  只补缺失项，不覆盖既有数据

*③ 报价表备注*
- 新增 `note` 字段；查询页切换器下方独立框体，无备注隐藏，切换即时刷新
- 「备注」随 Excel 往返读写；模板里的填写说明按前缀识别并忽略

*④ 吊绳三个缺陷*
- `getRopeBasePrice()` 对 ≤0 一律返回 `null` → 「不加吊绳」全 0 价被误判缺价并报
  「未设置 1000 张基准价」+ 整单标记缺价。
  修复：新增 `isFreeRope()` 识别全 0 免费选项，基准价补 0
- 吊绳 Excel 导入空单元格保留为 `null`（原折算 0），保住"缺价"语义
- `rebuildRopeUI()` 重渲染时按 `APP_PROFILE.defaultRope` 重置选中项 → 把用户选的吊绳换回默认，
  而调用顺序是"先 rebuild 再 onCalculate" → 报价算的是被换掉的吊绳。
  修复：保留当前选中项 + 重绑事件 + 刷新摘要
- 「恢复默认配置」里 `initOptions()` 重写 `els.rope.innerHTML` 后**没重绑 change 事件**
  → 之后切换吊绳完全无反应。修复：`initOptions()` 改走 `rebuildRopeUI()`

*⑤ 其他*
- `resetToDefaults` 中 `renderRopeRadios();` 是空调用（返回值被丢弃），已移除
- `parsePaperExcel` 开头两行紧邻 `throw`，第二行不可达（死代码），已删除
- 报价表模板元信息原一律用"当前报价表"，多报价表时会标错 → 改为按纸张所属报价表取名

**坑**
- **python `Path.write_text()` 在 Windows 上默认把 LF 转 CRLF** —— 批量改版本号后 6 个文件全变 CRLF，
  必须用 `write_bytes()` 或 `open(..., newline="\n")`，改完再扫一遍
- **顶层 `let`/`const` 不挂 `window`** —— jsdom 测试里 `window.ROPE_CONFIG` 恒为 `undefined`，
  要用 `window.eval("ROPE_CONFIG[0]")` 在页面上下文取值

**验证**：jsdom 21 项全绿。关键结论：
- 报价表下拉含 4 项（1楼 / 3楼 / 织边带（消光带）/ 电脑机）
- 切到唛头表备注框显示、切回 1楼 隐藏
- 不出血口径：80×40 = 3200 → 命中 `4*8` 档，1000 张单价 **240**；
  同尺寸按含出血口径（3569）应落 `4.5*8` —— 证明规则确实生效
- 不加吊绳：报价 0、无缺价警告、`costIncomplete = false`
- 切换吊绳后摘要即时更新；`rebuildRopeUI()` 保留当前选中吊绳

**部署**：本次改用**干净部署目录** `KOKALabel-v10.8.0`（只带站点必需文件），
不再把 `docs/`、`tests/`、`问题日志.md` 一起传上去。
