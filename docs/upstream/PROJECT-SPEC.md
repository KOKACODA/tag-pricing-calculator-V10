## 一、项目定位

给**吊牌 / 织唛 / 唛头类印刷品**做快速报价的内部工具。

核心价值：业务员输入几个参数（材质、尺寸、工艺、数量、吊绳、地区）就能拿到准确单价，
且价格表由管理员在线统一维护、一键同步给所有人。

**不是**面向终端客户的电商报价页面，也**不是**订单/CRM 系统。

---

## 二、目标用户与场景

| 角色 | 场景 |
|---|---|
| 业务员 | 客户询价时快速报出价格（含不同客户等级的差价） |
| 管理员 | 维护纸张/工艺/吊绳/邮费价格表，发布给全员 |
| 超管 | 管理账号、发布全局默认数据 |

**典型流程**：客户问"3楼 350 克铜版纸、40×60、烫金、1000 张、加普通吊绳、发广东" →
业务员在计算器选完参数 → 得到各客户等级的价格 → 报价。

## 三、功能范围

### 3.1 在范围内（已实现）

**计价核心**
- 多纸张同时报价（一次算多张纸，每张纸独立配置）
- 尺寸 → 面积 → 规格自动取档（支持手动切换代码）
- **是否出血**：报价表级开关，出血表自动 +3mm，不出血表按实际长宽
- 多工艺叠加
- 多批量档位（500 / 1000 / 2000 / 3000 / 5000 / 10000 …）
- 吊绳（1000 张基准倍数制，含「不加吊绳」免费选项）
- 邮费（按地区 × 档位查表；超 10000 张按重量 × 系数；中间档手输）
- 客户等级毛利系数（一次算多档）
- 直接系数模式（每张纸独立最高/最低倍数，中间等差插值）
- 批量直接报价（面积阈值内给固定价）
- 面积系数（面积 > 10000 时用最大规格 × 面积/10000）

**数据管理**
- 报价表组 / 报价表在线增删改
- 价格表就地编辑（点单元格直接改，有确认框）
- Excel 导入 / 导出 / 模板（格式与业务手工维护的表一致）
- 报价表备注展示

**账号与同步**（仅网页版）
- 四级角色：superadmin > admin > sales > visitor
- 云端全局默认数据 + 10 秒自动同步
- 报价历史 + 本地快照

**个性化**
- 默认纸张 / 默认吊绳 / 默认档位
- 界面字号（8~32px 可手输）

### 3.2 明确不在范围内

- 订单管理 / 发货 / 对账
- 客户 CRM
- 面向终端客户的自助下单
- 移动端 App

### 3.3 占位未实现

报价历史之外的云同步快照、客户管理、订单管理、统计报表、PDF 报价单、价格趋势

## 四、关键约束

1. **必须能离线用**：双击 `index.html` 即可运行，不依赖网络与服务器。
2. **不引入构建步骤**：任何打包/编译都会破坏第 1 条。
3. **数据要能平滑升级**：老用户 localStorage 里的旧结构必须能被迁移链无损升级。
4. **缺价必须显式暴露**：绝不能把"没定价"静默算成 0，否则会报出错误低价。
5. **价格表要可离线维护**：支持 Excel 往返，管理员不必登录系统就能改价。

---

## 五、成功标准

- 业务员报价速度显著快于手工算价，且不出错
- 管理员改一次价格表，全员 10 秒内同步到
- 本地与线上计算结果完全一致
