## 一、外部调研要点（与本项目相关的部分）

| 主题 | 业界实践 |
|---|---|
| 数据表格 | sticky 表头；行高密度三档（紧凑 40 / 标准 48 / 宽松 56px）；数字右对齐 + 等宽字体；列显隐/冻结管理；可保存筛选与列偏好；可展开行（渐进披露） |
| 表单/设置页 | 双列 Grid（`minmax(0,1fr)` 防撑破）；分组 fieldset + 留白代替分割线；必填红星 + 悬停说明；提交按钮固定视窗底部；helper 文本与字段绑定 |
| 布局 | 8px 基准栅格；F 型动线（重要操作左上）；行高 40-48px 替代传统 56px；7±2 控制导航项数 |
| 视觉 | 正文对比度 ≥4.5:1；动效 200-300ms；禁用态透明 40%；设计 token 管理（避免硬编码色值） |
| 无障碍 | 表格语义（scope/aria-sort/aria-expanded）；键盘走查；图表配数据表替代 |
| 性能 | 模块懒加载（Intersection Observer）；骨架屏；避免 4 层以上选择器嵌套 |

## 二、按页适配方案（现状对照 + 具体建议，均未实施）

### 2.1 全局（四页共性）

| 编号 | 建议 | 类别 | 代价 |
|---|---|---|---|
| G1 | **设计 token 化**：把散落的 `rgba(15,111,196,…)`、`#0f6fc4` 等收敛为 `--hover-bg` 等变量，主题色切换后 hover/高亮全覆盖（当前主题切换有部分硬编码色不跟随） | 视觉 | 低 |
| G2 | **表格行高密度三档**：紧凑/标准/宽松（约 34/42/50px），个性化面板加开关，存 localStorage | 视觉 | 低-中 |
| G3 | **sticky 表头**：历史表/价格矩阵/工艺表等长表格 `thead th { position: sticky; top: 0; background: 表头底色 }`，滚动时表头可见 | 交互 | 低 |
| G4 | **价格列右对齐 + 等宽字体**（`font-variant-numeric: tabular-nums`），纵向比对更易读 | 视觉 | 低 |
| G5 | **统一空状态/骨架屏**：空数据区加图标+引导文案的统一组件 | 视觉 | 中 |

### 2.2 智能报价计算器（用户确认无问题，仅微调）

### 2.3 报价表组查询（page-table）
| 编号 | 建议 | 类别 | 代价 |
|---|---|---|---|
