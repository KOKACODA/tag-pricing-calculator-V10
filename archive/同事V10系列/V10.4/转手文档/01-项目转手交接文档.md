## 一、项目一句话概述

吊牌印刷在线报价系统，纯前端单页应用（HTML+CSS+JS，零依赖、零构建），可选挂接 Cloudflare Pages 实现登录鉴权 + 云端默认数据共享。服务对象：KOKALabel 吊牌厂的销售/管理员。

## 四、技术架构

### 4.1 前端（无框架、无构建）
- 全部业务在 4 个文件：index.html（结构）、app.js（逻辑）、data.js（数据）、style.css（样式）。
- 页面切换：`switchPage(pageName)` 切换 `.page.active`（计算器/报价表组查询/个人主页）。
- **换皮不换骨原则**：历次 UI 重构全部保留元素 id 与业务逻辑，只动布局与 CSS。接手改 UI 时必须遵守。

### 4.2 数据层（localStorage）
存储键统一带前缀 `tagPricing_`（saveToStorage/loadFromStorage 自动加）：

| 键 | 内容 |
|---|---|
| paperConfig | 纸张报价数据（33 组 1 楼 + 10 张 3 楼，每组含各档位价格/直接系数/specs） |
| craftConfig | 附加工艺（按纸张 id 分组，36 组） |
| ropeConfig | 吊绳 27 组，v9.9 起为倍数制（1000 基准，500=1000 同价） |
| shippingConfig | 邮费 9 地区（basePrices 各档 / 超 10000 重量×系数） |
| priceLists / currentPriceListId | 报价表组列表与当前组 |
| customerLevels | 客户层级（普通/优质/大客户，可改名+系数） |
| appProfile | 个人主页设置（默认档位/吊绳/纸张/尺寸类型/小数位） |
| **dataVersion** | 迁移链基线，**当前 9.9.0**（注意：≠ UI 版本号！） |
| uiLayoutMode | UI 架构模式（v9.8：auto/flat/vertical，按设备存储） |

### 4.3 版本迁移链（data.js 尾部，IIFE 顺序执行）
- 每个迁移 = 一个 IIFE：读 dataVersion → `verCompare(dataVersion, "X") >= 0` 则跳过 → 改 localStorage（必要时同时重赋内存变量）→ 写入新 dataVersion。
- 迁移链：… → migrateFloor1V951(9.5.1) → **migrateRopeV99(9.9.0，最新)**
- ⚠️ 坑：迁移守卫曾被 sed 污染导致被跳过（migrateRename900Paper 已删除）。新增迁移必须：guard 用 verCompare、同时更新内存变量与存储、append 到链尾。

### 4.4 云端体系（网页版）
- **账号**：CF Pages Functions + Workers KV（namespace `KOKA_AUTH`，绑定名 AUTH）。键 `u:*`（用户，PBKDF2 100K 哈希）、`s:*`（会话）、`q:v1`（全局默认报价数据）。
- **角色**：superadmin > admin > sales > visitor（旧 role:user 自动归一 sales）。规则：管理员互管不删自己、默认保留 ≥1 管理员、停用即时生效。
- **云端默认数据流**：超管在「报价表组查询」页点「↑保存为全局默认」→ POST /api/quote → KV q:v1 → **所有角色每 10 秒** syncCloudQuote() 检测 updatedAt 变化 → toast 提示 1 秒后 location.reload()。
- **首次部署**需环境变量 SETUP_KEY / ADMIN_USER / ADMIN_PASS（创建初始 admin）。

## 六、关键业务规则（改逻辑前必读）

1. **报价计算**（app.js `calculate()`）：
   - 纸张：按面积定位规格代码 → 取档位价 → 乘客户折扣 → 面积 >10000mm² 且无对应面积代码时乘面积系数（面积/10000，四舍五入两位）。
   - **工艺费（v10.2 起，标准报价模式）**：工艺循环在纸张价之前完成，`(纸张价 + 工艺费) × 折扣`（再乘面积系数）；`craftTotal` 仅作明细展示，**不再单独计入 cost**。直接系数模式维持 v7.2 逻辑（`(纸张+工艺)×系数`，baseUnitPrice 不含工艺，勿重复并入）；批量直接报价纸张工艺直接叠加。
   - **吊绳（v9.9 倍数制）**：基准价 = rope.prices["1000"]（回退 500 档）；500 张=基准；其他档 = 基准 × (档位/1000)，Math.round 保留 2 位。任意档位可算。>1000 档明细行显示 `（¥基准/千张 × 倍数 = ¥结果）`。
   - 邮费三模式：固定档直查 / >10000 按重量×地区系数 / 中间档手动输入。
   - 批量直接报价纸张（batchDirect）：价格固定，不打折不乘面积系数，工艺费直接叠加。
2. **两种计价模式**：标准报价（v10.0 起默认，按钮在前）/ 直接系数计算，mode-btn 切换（localStorage currentCalcMode 记忆用户选择）。
3. **UI 架构模式（v9.8）**：body.ui-flat（桌面/iPad：左侧 sidenav + calc-grid 双栏）/ body.ui-vertical（手机：顶部横条 + 单栏卡片=垂直纵深式）。auto 模式按 UA 检测手机；个人主页-报价设置可手动切换（localStorage uiLayoutMode，按设备存储，不入云同步）。
4. **SKU 芯片**：纸张材质默认 sku-grid 直选芯片，全称放 title 悬浮；`.paper-option` 的 class 与 data-sheet/data-paper 属性是 onPaperChange 的契约，勿改。下拉模式（paperSelectMode=dropdown）复用 `startCellEdit` 无关的旧版 `togglePaperDropdown/filterPaperOptions/paperMatchesSearch`（这些函数曾为死代码，v10.1 复活）。
5. **价格表内联编辑机制**（v7.9 起，v10.3 扩展）：`startCellEdit`（文本/数值按 type 区分）→ `commitCellEdit`（数值相等短路 / 清空 / confirm 差异提示）→ `applyPriceEdit`（按 data-type 落盘 + saveToStorage）。新增编辑类型时三处都要加分支（参考 spec-code / spec-maxarea / tier-name）。

## 九、版本管理规范（血泪教训）

1. **版本号更新禁用 sed 全局替换**——v9.4.1~v9.5.2 的版本串全部静默失败。**必须用 python 精确替换**，串清单：`v=9.X.0`（资源引用）、`v9.X.0`（标题/注释）、`"9.X.0"`（app.js 备份 JSON version 字段）。data.js 的 dataVersion（9.9.0）与 UI 版本号含义不同，勿连带。
2. **改 HTML 必做 div 栈式配对校验**（曾漏 1 个闭合导致结构错位）——用正则抽标签栈模拟配对，全部标签 + 关键 id 清单断言。
3. JS 改完 `node --check` 三个 js 文件。
4. 流程惯例：从当前稳定分支切 `vX.Y-dev` 分支 → 改 → 校验 → commit（中文详细 message）→ 打 tag vX.Y.0 → 推 GitHub → 部署 CF → 复制生产包到 `Desktop\KL\9ge tebieban\vX.Y\` 并 MD5 校验 → CHANGELOG + docs/plans + .workbuddy/memory 日志。
5. **废案不删除**：v9.5-redesign、v9.7-flat 等分支/tag/归档全部保留。
6. `git add -A` 注意 .wrangler/（已 gitignore，别误提交）。
7. **版本号替换必须豁免 data.js 迁移串**（v10.0 再次踩中）：替换 `v=X.Y.Z` 时，data.js 的 `verCompare(dataVersion, "9.9.0")` / `saveToStorage("dataVersion", "9.9.0")` 是**数据迁移基线**，与 UI 版本号含义不同——例如升 v10.0 时它们不能被改成 "10.0.0"。脚本应只替换 `v=10.x`、`v10.x`、`"10.x"` 三种形态并对 data.js 单独确认。
8. **改 CSS 覆盖布局属性时先查原值**（v10.1 吊绳折叠踩坑）：`display:flex` 覆盖了原 `grid`（三列），导致展开后芯片被压成一行竖条。折叠类需求优先用 `:not(.open){display:none}` 只控隐藏，不干预展开时的布局属性。
9. **覆盖 `hidden` 属性的 CSS 会致"卡死"**（v10.1→v10.2）：`.modal-mask{display:flex}` 会覆盖 `[hidden]{display:none}`，遮罩常驻并拦截全部点击。用 class 控制显隐（`.panel.open`），不要依赖 hidden 属性 + 强制 display。
