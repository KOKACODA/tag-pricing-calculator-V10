#### 二、UI 框体溢出与规范问题修复（5 处）

##### 1. 报价结果表格撑破整页（桌面端横向溢出 49px）

- **根因链**：`.result-section` 是 `display:grid`（`style.css:696`）→ 隐式列宽默认 `auto` → 被 5 列表格按 `min-content` 撑到 **493px** → 逐层传导 `.result-row`(493) → `.result-table-scroll`(493) → 超出 `.calc-result-col`(453) → 整页出现横向滚动条（`docScrollW=1474 > clientW=1425`）。
- **修复**：
  - `.calc-result-col .result-section { grid-template-columns: minmax(0, 1fr) }` 显式约束隐式列；
  - 表格外包 `.result-table-scroll{ width:0; min-width:100%; overflow-x:auto }` —— `width:0 + min-width:100%` 技巧让滚动容器自身不参与内容撑宽计算，表格过宽时在容器内横向滚动。
- **验证**：修复后 `result-section=403, result-row=403, scroll=403`，`docScrollW=1425=clientW`。

##### 2. 手机端导航按钮被挤出视口 13px

- **根因**：`body.ui-vertical .sidenav-menu .nav-btn { flex: 1 }` 使三个按钮平分宽度后总宽超出容器。
- **修复**：改 `flex: 0 0 auto; white-space: nowrap`（按钮按内容自适应）+ `.sidenav-menu { overflow-x: auto; scrollbar-width: none }` 允许横向滑动。
- **附带排查**：曾尝试 `flex: 1 1 0` + 省略号，会导致按钮文字被截断成「智能…」，随即改回 `flex: 0 0 auto`。

##### 3. 手机端下拉弹窗下溢视口 71px

- **根因 1**：`adjustDropdownPosition()` 计算可用高度时未扣除弹窗自身 `padding + border`（`boxOverhead`）与 sticky 搜索区高度（`searchH`）。
- **根因 2**：`togglePaperDropdown()` 仅通过 `requestAnimationFrame` 调用定位，被浏览器节流时停留在 CSS 默认 `max-height: 300px`。
- **修复**（JS）：
  ```js
  // v10.5：双保险定位——同步一次 + 下一帧复测一次。
  adjustDropdownPosition(dropdown);
  requestAnimationFrame(() => adjustDropdownPosition(dropdown));
  ```
  并在定位函数中扣除开销、加下限：
  ```js
  const usableBelow = spaceBelow - boxOverhead;
  const usableAbove = spaceAbove - boxOverhead;
  options.style.maxHeight = Math.max(120, Math.min(usableBelow, 400)) + "px";
  ```
- **修复**（CSS 兜底）：`.paper-dropdown-inline .paper-options { max-height: min(300px, 52vh) }`；`@media (max-width:520px)` 为 `46vh`。
- **验证**：弹窗下溢 0px、右溢 0px（三视口）。

##### 4. 桌面端「订单备注」textarea 右溢 30px

- **根因**：`.quote-save-fields { grid-template-columns: minmax(180px, .7fr) minmax(260px, 1.3fr) }` 第二列最小宽 260px 强制撑破窄侧栏。
- **修复**：改为 `minmax(0, .7fr) minmax(0, 1.3fr)`；并在 `.calc-result-col` 内强制单列。

##### 5. 全局防溢出兜底 + 弹窗宽度规范

- `.app-shell / .pages / .page / .calc-grid / .calc-form-col / .flat-section / .sheet-card` 统一补 `max-width:100%; box-sizing:border-box`；`.pages { overflow-x: clip }`。
- 下拉弹窗宽度：`min-width: min(420px, calc(100vw - 24px)); max-width: calc(100vw - 24px)`，确保窄屏不出界。
- 手机端导航字号微调：`@media (max-width:480px)` 下 `padding:10px 9px; font-size:12.5px`。

1. **免登录 UI 探针法**：Edge headless + `file:///` 协议（`auth.js` 仅在 http/https 强制登录）+ `--allow-file-access-from-files` + 预写 `localStorage` 模拟布局模式。

2. **Edge 命令坑**：`--screenshot` / `--dump-dom` 的输出路径**必须用 Windows 原生反斜杠**（`C:\...`），用 `/c/...` 会报 `0x3 系统找不到指定的路径`。
3. **真实溢出判定**：必须**排除可滚动祖先内的元素**，否则会把"滚动内容"误报为"溢出缺陷"。
4. **溢出治理三模式**：grid 容器 `minmax(0, 1fr)` ／ flex 项 `min-width: 0` ／ 滚动容器 `width: 0 + min-width: 100%`。
5. **本机环境**：PowerShell stdout 不回传 → 一律用 Bash + 显式 `export PATH` + 落盘 + Read。
