# KOKALabel 报价系统 · 网站使用 SOP 手册

> 适用版本：v9.4.3 ｜ 更新日期：2026-09-08
> 适用站点：https://kokalabel-quote.pages.dev
> 适用对象：超级管理员 / 管理员 / 业务员 / 访客

---

## 0. 快速上手（3 步）

1. 浏览器打开 **https://kokalabel-quote.pages.dev**
2. 输入管理员分配的 **账号 + 密码** → 登录（未分配请联系管理员开通）
3. 进入「智能报价计算器」→ 选纸张/规格 → 点【报价】即可查看成本与报价

> 提示：每次功能更新后请按 **Ctrl+F5（或手机清缓存）** 强制刷新，确保加载最新版本。

---

## 1. 登录与账号

### 1.1 登录
- 打开站点后会自动跳转到登录页（`login.html`）。
- 输入「账号」（字母/数字，小写）与「密码」（≥6 位）→ 点【登录】。
- 登录成功后进入系统；右上角导航栏右端显示**当前账号 + 角色徽章 + 退出**。
- 会话有效期 7 天；退出请点右上角【退出】。

### 1.2 修改自己的昵称 / 密码
- 「个人主页」→ 顶部「当前账号」卡片右侧：【修改昵称】【修改密码】。
- 修改密码后需用新密码重新登录。

### 1.3 忘记密码 / 需要重置
- 联系**超级管理员或管理员**：账号管理 → 该账号行 →【重置密码】，重新分配新密码。
- 访客/业务员没有管理权限时，无法自助重置。

### 1.4 常见登录失败提示及处理
| 提示 | 含义 | 处理 |
|---|---|---|
| 账号不存在 | 输入错误或未开通 | 核对账号，联系管理员 |
| 密码错误 | 密码不对 | 重新输入或找管理员重置 |
| 账号已被停用 | 管理员已停用 | 联系管理员启用 |
| 账号使用期限已到 | 授权到期 | 联系管理员【设时长/到期】续期 |
| 系统未初始化 | 后台管理员未完成首次初始化 | 联系管理员用初始化密钥处理 |
| 无法连接激活服务器… | 网络问题 | 检查网络后重试 |

## 2. 角色权限速查

| 角色 | 可用页面 | 查看报价表 | 修改/发布报价 | 账号管理 | 典型用途 |
|---|---|---|---|---|---|
| **超级管理员** | 全部 | ✅ 可改价 | ✅ 改价 + 发布全局默认 | ✅ 全权 | 报价维护、发号、全局管理 |
| **管理员** | 全部 | ✅（只读） | ❌ | ✅ 互管/管子账号 | 日常账号与人员管理 |
| **业务员** | 全部 | ✅（只读） | ❌ | ❌ | 报价、查价、谈客户 |
| **访客** | 仅计算器 | ❌ | ❌ | ❌ | 只算价格、不对内开放其它页面 |

> 报价表数据对管理员/业务员为**只读**：点击价格单元格会提示「仅超级管理员可修改」。

## 3. 访客操作 SOP（仅计算器）

1. 登录后只看到「智能报价计算器」页（顶部只有该入口）。
2. 按第 5 节流程报价。
3. 退出：右上角导航栏右端【退出】。
4. 看不到「报价表组查询 / 个人主页」属正常（权限限制）。

## 4. 业务员操作 SOP（全页面只读）

1. 登录后可见全部 3 个页面。
2. 报价：走「智能报价计算器」。
3. 查价：进「报价表组查询」→ 顶部切换「报价表（1楼/3楼）+ 报价组」，搜索代码/面积、上一张/下一张浏览价格表。
4. **只读提醒**：报价表价格不可改；需要调价请报超级管理员。
5. **数据自动更新**：当超管发布新的全局默认报价后，页面最长 10 秒内自动检测并提示「检测到超管发布的【新报价数据】，正在刷新应用…」，自动刷新后即为最新价目。**正在输入报价时若出现该提示，说明价格已更新，请以刷新后数据为准。**

## 5. 智能报价计算器 — 标准操作流程

### 5.1 算价步骤
1. **张数**：调整纸张数量（默认 1 张，可加）。
2. **选纸**：每张纸卡片点「纸张材质」下拉 → 展开选择（1楼 28 个报价组 / 3楼 10 张），选择后自动收起。
3. **规格**：输入纸宽(mm)、纸长(mm)；有报价上限面积时按提示选代码；也可直接选规格代码（代码即面积档）。
4. **批量/计价模式**：
   - 【标准报价】：按批量档位（500/1000/2000…）+ 折扣 + 吊绳邮费计算；
   - 【直接系数计算】：纸张有直接系数档位（按批量选档，显示最高/最低倍数），按系数直算。
5. **工艺**：点开「附加工艺」（默认折叠）→ 勾选工艺（烫金/压凹/UV…），可多选。
6. **吊绳**：点开「吊绳类型」（默认折叠）→ 选不加/普通/各类吊绳。
7. **邮费**：选地区（邮费表 9 地区）→ 自动按重量/件数三档计算；需要可手工调整。
8. 点【报价/计算】→ 下方「报价结果」显示：成本、吊牌成本合计、各客户层级报价（普通/老客户…）。

### 5.2 快捷调整
- **临时系数**：输入倍数（如 `1.18`）→ 所有报价 × 系数（临时试价用）。
- **邮费快速修改**：输入修改后的邮费 → 与临时系数同用时并排显示两种结果：
  - 蓝卡「改邮费后成本 × 系数」（邮费也乘系数）
  - 绿卡「成本 × 系数 + 新邮费」（邮费不乘系数）
- 当前纸张可在「上一张/下一张」间快速切换。

### 5.3 保存与导出
- **保存报价 / 查看报价记录**：本机保存报价单，可随时回看。
- **导出当前报价表 Excel / 导入报价表 Excel / 下载 Excel 模板**：整表级数据维护。
- **保存到本地文件 / 从本地文件恢复 / 本地快照**：完整配置备份（恢复前请谨慎，会覆盖当前数据）。

> 计算器默认：附加工艺、吊绳类型默认**折叠**，点标题展开。

## 6. 管理员操作 SOP（账号管理）

进入「个人主页」→「账号管理」卡片。

### 6.1 新增账号
1. 填写：账号（唯一，小写字母数字）、初始密码（≥6）、昵称（选填）、角色、使用天数（空=永久）。
2. 点【新增】→ 提示“已创建”。
3. 把账号+初始密码发给使用者，建议其登录后改密码。

### 6.2 常用操作（行内按钮）
| 操作 | 用途 |
|---|---|
| 角色 | 改角色（业务员/访客/管理员；超管可设超管） |
| 改昵称 | 修改显示名称 |
| 重置密码 | 使用者忘密码时重新分配 |
| 设时长 | 续期/缩短（天数；留空=永久） |
| 停用 / 启用 | 立即禁用（该账号再登录被拒）或恢复 |
| 删除 | 永久移除账号 |

### 6.3 规则（系统强制）
- 不能删除/停用**自己**；
- 管理员之间可互管互删，但**不能动超级管理员**；
- 系统**默认保留至少 1 个管理员**（试图删除/停用最后一名管理员会被拒绝）；
- 只有超管能创建/升降“超级管理员”。

## 7. 超级管理员 SOP（报价维护 + 全局发布）

### 7.1 改价并发布为全局默认
1. 进「报价表组查询」→ 切到要改的报价表/纸张。
2. 点价格单元格 → 弹窗显示原值 → 输入新值 →【确认】→ 提示“价格已更新”（保存到本机）。
3. 修改完成后点右上角【↑ 保存为全局默认（云端共享）】→ 确认。
4. 成功后提示“已发布为全局默认”；**所有账号（含其它超管/管理员）最长 10 秒内自动收到并刷新**到该版本。
5. 变更记录可通过导出/本地快照留存。

### 7.2 注意
- 你本地**未发布**的修改，若遇到其它超管发布新版会被覆盖（刷新前有提示）——养成“改完即发布”的习惯；
- 发布是全量（纸张/工艺/吊绳/邮费四套一起），确认无误再发布；
- 想整体换价格：用「导入报价表 Excel / 导入配置 JSON」等先导入，核对后再发布。

### 7.3 数据备份建议
- 每周在「个人主页 → 本地快照 → 创建当前快照」留存快照；或「保存到本地文件」导出 JSON 备份到 U 盘/网盘。

## 8. 到期与续期

- 子账号到期：登录被拒「账号使用期限已到」→ 由管理员在该账号行【设时长】续期；
- 账号使用期限记录在账号管理列表“状态/期限”列；永久账号显示“永久”。

## 9. 常见问题 FAQ

**Q1 业务员说价格没更新？**
A：超管发布后最长 10 秒自动刷新；若未刷新，手动 F5；仍旧 → 看是否浏览器缓存（Ctrl+F5）。

**Q2 访客为什么没有“个人主页”？**
A：角色是“访客”时只开放计算器，属正常。

**Q3 我不小心点错了价格并发布了？**
A：超管可在报价表页把价格改回 → 重新【保存为全局默认】发布即可覆盖。若不确定原值，用本地快照/备份恢复后再发布。

**Q4 想加一个人用系统，怎么最快？**
A：管理员 → 个人主页 → 账号管理 → 新增（角色：访客或业务员），把账号密码发对方。

**Q5 账号到期了还能看到历史吗？**
A：到期后登录被拒；管理员续期后即可恢复。

**Q6 超级管理员账号丢了怎么办？**
A：这是最高权限账号，请务必保存好；如遗忘密码，需通过 Cloudflare 项目环境变量/后端数据重置（联系开发者），勿将超管密码随意分享。

**Q7 手机能登录吗？**
A：可以，浏览器直接访问即可（界面按桌面布局设计，建议平板/电脑体验最佳）。

## 10. 安全与数据提醒

- 请勿共享账号；访客/业务员账号权限有限，超管/管理员账号不要外借；
- 定期修改密码（个人主页）；
- 报价默认数据发布操作只由超管执行，避免多人同时改价冲突；
- 本地有离线可用（`file://` 双击 index.html）形态，离线版与网页版相互独立，离线版改价不会自动同步云端；
- 删除账号不可恢复，删除前请确认。
