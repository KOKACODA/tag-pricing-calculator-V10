## 一、项目一句话概述

吊牌印刷在线报价系统，纯前端单页应用（HTML+CSS+JS，零依赖、零构建），可选挂接 Cloudflare Pages 实现登录鉴权 + 云端默认数据共享。服务对象：KOKALabel 吊牌厂的销售/管理员。

## 四、技术架构

### 4.1 前端（无框架、无构建）
- 全部业务在 4 个文件：index.html（结构）、app.js（逻辑）、data.js（数据）、style.css（样式）。
- 页面切换：`switchPage(pageName)` 切换 `.page.active`（计算器/报价表组查询/个人主页）。
- **换皮不换骨原则**：历次 UI 重构全部保留元素 id 与业务逻辑，只动布局与 CSS。接手改 UI 时必须遵守。

### 4.2 数据层（localStorage）
存储键统一带前缀 `tagPricing_`（saveToStorage/loadFromStorage 自动加）：

| 键 | 内容 |
|---|---|
| paperConfig | 纸张报价数据（33 组 1 楼 + 10 张 3 楼，每组含各档位价格/直接系数/specs） |
| craftConfig | 附加工艺（按纸张 id 分组，36 组） |
| ropeConfig | 吊绳 27 组，v9.9 起为倍数制（1000 基准，500=1000 同价） |
| shippingConfig | 邮费 9 地区（basePrices 各档 / 超 10000 重量×系数） |
| priceLists / currentPriceListId | 报价表组列表与当前组 |
| customerLevels | 客户层级（普通/优质/大客户，可改名+系数） |
| appProfile | 个人主页设置（默认档位/吊绳/纸张/尺寸类型/小数位） |
| **dataVersion** | 迁移链基线，**当前 9.9.0**（注意：≠ UI 版本号！） |
| uiLayoutMode | UI 架构模式（v9.8：auto/flat/vertical，按设备存储） |

### 4.3 版本迁移链（data.js 尾部，IIFE 顺序执行）
- 每个迁移 = 一个 IIFE：读 dataVersion → `verCompare(dataVersion, "X") >= 0` 则跳过 → 改 localStorage（必要时同时重赋内存变量）→ 写入新 dataVersion。
- 迁移链：… → migrateFloor1V951(9.5.1) → **migrateRopeV99(9.9.0，最新)**
- ⚠️ 坑：迁移守卫曾被 sed 污染导致被跳过（migrateRename900Paper 已删除）。新增迁移必须：guard 用 verCompare、同时更新内存变量与存储、append 到链尾。

### 4.4 云端体系（网页版）
- **账号**：CF Pages Functions + Workers KV（namespace `KOKA_AUTH`，绑定名 AUTH）。键 `u:*`（用户，PBKDF2 100K 哈希）、`s:*`（会话）、`q:v1`（全局默认报价数据）。
- **角色**：superadmin > admin > sales > visitor（旧 role:user 自动归一 sales）。规则：管理员互管不删自己、默认保留 ≥1 管理员、停用即时生效。
- **云端默认数据流**：超管在「报价表组查询」页点「↑保存为全局默认」→ POST /api/quote → KV q:v1 → **所有角色每 10 秒** syncCloudQuote() 检测 updatedAt 变化 → toast 提示 1 秒后 location.reload()。
- **首次部署**需环境变量 SETUP_KEY / ADMIN_USER / ADMIN_PASS（创建初始 admin）。

## 六、关键业务规则（改逻辑前必读）

1. **报价计算**（app.js `calculate()`）：
   - 纸张：按面积定位规格代码 → 取档位价 → 乘客户折扣 → 面积 >10000mm² 且无对应面积代码时乘面积系数（面积/10000，四舍五入两位）。
   - **吊绳（v9.9 倍数制）**：基准价 = rope.prices["1000"]（回退 500 档）；500 张=基准；其他档 = 基准 × (档位/1000)，Math.round 保留 2 位。任意档位可算（3500/7500 等不再报"无定价"）。>1000 档明细行显示 `（¥基准/千张 × 倍数 = ¥结果）`。
   - 邮费三模式：固定档直查 / >10000 按重量×地区系数 / 中间档手动输入。
   - 批量直接报价纸张（batchDirect）：价格固定，不打折不乘面积系数，工艺费直接叠加。
2. **两种计价模式**：直接系数计算（默认）/ 标准报价，mode-btn 切换。
3. **UI 架构模式（v9.8）**：body.ui-flat（桌面/iPad：左侧 sidenav + calc-grid 双栏）/ body.ui-vertical（手机：顶部横条 + 单栏卡片=垂直纵深式）。auto 模式按 UA 检测手机；个人主页-报价设置可手动切换（localStorage uiLayoutMode，按设备存储，不入云同步）。
4. **SKU 芯片**：纸张材质是 sku-grid 直选芯片（无下拉无搜索），全称放 title 悬浮；`.paper-option` 的 class 与 data-sheet/data-paper 属性是 onPaperChange 的契约，勿改。

## 八、GitHub 推送 SOP（有坑，必须按此操作）

**坑**：本机 hosts 文件（C:\Windows\System32\drivers\etc\hosts 第 93~122 行）把 github.com 系列全部指向 127.0.0.1，本机 443 有假服务 → TLS 握手必挂 `CRYPT_E_NO_REVOCATION_CHECK`。nslookup 正常，hosts 才是元凶（疑似"屏蔽摸鱼网站"工具写入）。

**绕行方案**（已验证可用，网络时好时坏需重试 2~3 次）：
```bash
env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY \
git -c http.schannelCheckRevoke=false \
    -c http.curloptResolve="github.com:443:20.205.243.166" \
    push origin <分支/tag>
```
（绕代理 env + 跳过吊销检查 + 固定 GitHub 真实 IP。fetch/ls-remote 同理。）
